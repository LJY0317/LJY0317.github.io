만든 것들

개인 프로젝트와 SSAFY에서 만든 팀 작업을 함께 정리했습니다.

Pawpaw Town

개인 작업 · Unity

작업실, 주방, 다락방을 돌아다니는 Unity 게임을 만들고 있습니다. 캐릭터 움직임과 방의 조명, 화면 설정을 직접 시험하며 고쳐왔습니다.

PhotoArchiveKit

개인 작업 · Swift

사진과 동영상을 컴퓨터에서 직접 검사하고, 같은 파일을 찾아 검토·정리하는 프로그램입니다.

AgriBot

SSAFY 팀 프로젝트 · 로봇

식물을 선택하면 로봇이 온실 안을 이동해 상태를 확인하는 ROS 2·Gazebo 기반 시뮬레이션입니다.

Dayori

SSAFY 팀 프로젝트 · 모바일 앱

시간표, 일정, 필기, 스티커를 한 곳에서 관리하는 앱입니다. 시간표 이미지와 에브리타임 공유 링크에서 수업을 가져오는 기능을 작업했습니다.

Plura Desktop

개인 작업 · 데스크톱 도구

한 앱에서 계정을 번갈아 바꾸는 것이 번거로워 프로필마다 독립된 창을 실행하도록 만들었습니다.

ChatGPT Tela

개인 작업 · 개발 도구

대화창과 개발 환경 사이에서 코드나 실행 결과를 계속 옮겨 적는 것이 번거로워 시작한 연결 도구입니다. 아직 개발 중입니다.

Togethy

SSAFY 팀 프로젝트 · 웹

스터디 검색, 그룹 운영, 영상 모임 등을 포함한 팀 서비스입니다. 저는 React 화면의 빌드 오류와 서버 통신 문제를 수정했습니다.

MOUDA

2인 팀 프로젝트 · 금융 정보

ETF 종목과 시세, 관련 기사 등을 찾아볼 수 있는 금융 정보 웹 서비스입니다. 저는 데이터 수집, 중복 처리, 조회 API와 차트를 담당했습니다.

다른 분야에서 시작했습니다.

대학교에서는 영문학을 공부했고, 지역아동센터에서 아이들의 공부를 도운 적이 있습니다. 한국 생활이 익숙하지 않은 친구들이 온라인 서비스에 가입하기 어려워하는 모습을 보면서 사람마다 같은 화면을 다르게 받아들인다는 것을 느꼈습니다.

SSAFY에 들어가 처음 개발을 배운 뒤 로봇과 모바일 앱을 팀원들과 만들었습니다. 지금은 생활 속에서 불편했던 일을 개인 프로그램으로도 만들어 보고 있습니다.
