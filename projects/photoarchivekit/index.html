PhotoArchiveKit

개인 프로젝트

Personal project

만든 이유와 처리 방식

Purpose and processing

사진 정리를 AI에 맡기는 방법을 생각하다가 원본과 촬영 정보까지 전달하는 것이 신경 쓰였습니다. 파일을 읽고 같은 내용을 찾는 작업은 컴퓨터에서 처리하고, AI에 전달하는 결과는 따로 구성했습니다. 사람이 확인하는 화면에는 미리보기를 남기고 AI용 결과에서는 파일명, 경로, 촬영 정보와 해시값을 제외했습니다.

I wanted help organizing photos without sending originals and capture details to an AI. The computer reads and compares files locally. People can review previews in the app, while the AI-facing output omits filenames, paths, capture metadata, and hashes.

중복 파일 처리

Handling duplicates

파일 내용이 정확히 같은 사진과 동영상을 찾습니다. Live Photo는 사진과 동영상이 한 쌍이므로 함께 다루도록 했습니다. 검사 중에는 파일을 바꾸지 않고, 결과를 확인한 뒤 휴지통이나 격리 폴더로 옮길 수 있게 했습니다. 격리한 파일을 복구하는 기능도 구현했습니다.

The checker detects exact file duplicates and treats Live Photos as paired photo-and-video assets. Scanning leaves files unchanged. After review, selected files can be moved to Trash or quarantine, with restoration from quarantine.

출력 옵션 정리

Output options

명령행 출력은 일반 텍스트, JSON, AI용 JSON으로 구분했습니다. JSON 출력 옵션 두 개를 동시에 선택했을 때의 처리를 한곳으로 모아, 옵션을 해석하는 코드가 중복되지 않도록 수정했습니다.

The CLI has text, JSON, and agent-focused JSON output. I consolidated parsing and validation so conflicting JSON options are handled in one place.
