PhotoArchiveKit

A safer way to inspect and clean up photo libraries.

GitHub repository ↗

Native review of exact duplicate files, with reversible cleanup and careful Live Photo handling.

  • Scans multiple local roots and groups exact duplicates.
  • Keeps human review in a SwiftUI comparison flow.
  • Moves reviewed duplicates to Trash or quarantine; supports verified restoration.
