PhotoArchiveKit

중복 사진을 찾으면서 사진 원본을 AI에 넘기지 않는 방법을 고민했습니다.

사진과 동영상을 컴퓨터에서 직접 검사하고, 같은 파일을 찾아 검토·정리하는 프로그램입니다.

GitHub에서 코드 보기다른 프로젝트 보기

사진을 AI에 보여줘야 할까

사진 보관함을 정리하는 일은 귀찮습니다. AI에게 파일 정리를 맡기는 방법을 생각하다가, 사진 원본이나 촬영 시각, 파일 경로까지 전달하는 것이 신경 쓰였습니다. 중복 사진을 찾는 데 이 정보가 꼭 필요하지는 않을 것 같았습니다.

그래서 파일을 읽고 중복을 계산하는 부분은 로컬 프로그램으로 만들었습니다. AI에 넘기는 결과는 따로 구성해 파일명과 경로, 원본 해시를 제외했습니다. 사용자는 앱 화면에서 사진을 보고 직접 판단할 수 있습니다.

실수로 지우지 않으려면

사진을 찾는 기능보다 삭제를 조심스럽게 처리하는 쪽을 더 오래 고민했습니다. 검사는 읽기 전용으로 하고, 후보를 확인한 다음 휴지통으로 보내거나 따로 격리할 수 있게 했습니다. 격리한 파일은 다시 복구할 수 있습니다.

Live Photo는 사진 하나와 짧은 동영상 하나가 짝이므로 두 파일을 함께 다뤘습니다. 지금 구현한 중복 판별은 내용이 정확히 같은 파일을 대상으로 합니다.

AI에 보여줄 내용은 따로 만들었습니다

사람이 파일을 확인하는 화면과 AI가 읽을 정보를 같은 형태로 만들고 싶지 않았습니다. 사람이 볼 때는 미리보기가 필요하지만 AI에는 검사한 파일의 원본을 보여줄 필요가 없었습니다.

명령행에서도 일반 텍스트, JSON, AI용 JSON을 구분했습니다. 두 JSON 출력 옵션을 동시에 선택했을 때 어떻게 처리할지도 한곳에서 정리했습니다. 공개 저장소에는 처음 공개한 버전과 이 출력 옵션을 정리한 수정 기록이 남아 있습니다.
