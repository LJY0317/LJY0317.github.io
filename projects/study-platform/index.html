팀 서비스와 담당 업무

Team product and role

스터디를 찾고 온라인 모임에 참여할 수 있는 팀 서비스입니다. 스터디 탐색, 영상 모임, 파일 공유와 요약 등의 기능을 팀에서 개발했습니다. 저는 React·TypeScript 프론트엔드에서 빌드 오류와 API 응답 처리 문제를 수정했습니다.

The team built study-group discovery, online meetings, file sharing, and summaries. I worked on build errors and API response handling in the React and TypeScript frontend.

서버 연결 수정

API connection fixes

일부 화면은 서버 응답을 실제 형식과 다르게 처리하고 있었습니다. 응답에 맞춰 화면 처리 코드를 고쳤습니다. 또 일부 요청이 공통 환경 설정을 사용하지 않고 localhost로 향하고 있어, Vite 환경 설정의 서버 주소를 사용하도록 정리했습니다.

Some screens assumed a response shape that differed from the backend. I corrected that handling and replaced hard-coded localhost URLs with the API address from the shared Vite environment settings.

화면 코드를 고친 뒤에는 실제 요청이 설정한 서버로 가는지도 확인했습니다. 팀에서 만든 화면과 서버를 연결하며 응답 형식과 실행 환경을 맞춘 작업이었습니다.

After changing the screen code, I checked the request destination in the running environment and aligned it with the team's backend.
