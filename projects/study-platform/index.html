Togethy

스터디를 찾고 모임을 이어갈 수 있는 서비스.

스터디 검색, 그룹 운영, 영상 모임 등을 포함한 팀 서비스입니다. 저는 React 화면의 빌드 오류와 서버 통신 문제를 수정했습니다.

프로젝트에서 맡았던 일

여러 사람이 함께 만드는 서비스라 화면과 서버가 맞물려 돌아가는지 확인하는 일이 중요했습니다. React·TypeScript 프론트엔드에서 빌드 오류가 나던 파일을 고치고, 실제 서버 응답과 맞지 않던 처리 코드를 수정했습니다.

일부 요청은 설정된 서버 주소 대신 localhost로 가고 있었습니다. 각 기능에서 따로 넣어둔 주소를 정리해 Vite 환경 설정을 사용하도록 수정했습니다.

전체 서비스의 모습

사용자는 스터디를 찾아 가입하고 영상 모임에 참여할 수 있습니다. 파일 공유와 알림, 모임 요약 등은 팀에서 함께 만든 기능입니다. 저는 제가 고친 화면과 통신 부분을 중심으로 설명합니다.
