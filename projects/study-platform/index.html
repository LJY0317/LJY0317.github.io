Context

How the service works

Togethy brings finding a study group and running one into the same service. The team built study matching, group management, video meetings, shared files, notifications, and meeting summaries.

Students can browse study groups, manage sessions, and meet online. The service brings together group discovery, video meetings, shared documents, and AI-generated meeting summaries.

Engineering note

React build and API fixes

Problem

Unused code, outdated types, and incorrect assumptions about the API response caused problems. Some requests also used localhost rather than the Vite environment setting.

Action

  • Fixed npm build errors in three frontend files.
  • Removed stale types, unused imports and state, and an obsolete rejection path.
  • Removed a helper based on an incorrect backend response shape.
  • Removed localhost fallbacks from two API hooks and used the Vite environment configuration instead.

Result

I fixed the build issues and switched API requests to use the configured Vite base URL.
