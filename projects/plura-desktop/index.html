Plura Desktop

Multiple independent ChatGPT Desktop profiles on one Mac.

GitHub repository ↗

A profile-management utility for running separately configured ChatGPT Desktop windows.

  • Creates and manages separate ChatGPT Desktop profile apps.
  • Preserves the official app and default profile.
  • Provides lifecycle and status commands with a Homebrew installation path.
