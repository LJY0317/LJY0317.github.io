Plura Desktop

ChatGPT를 계정과 작업별로 따로 실행하는 도구.

한 앱에서 계정을 번갈아 바꾸는 것이 번거로워 프로필마다 독립된 창을 실행하도록 만들었습니다.

계정 전환이 귀찮아서

ChatGPT를 서로 다른 계정이나 작업에 쓰면서 매번 프로필을 바꾸는 것이 불편했습니다. 공식 앱을 바꿔서 만드는 대신 기존 앱을 그대로 두고 필요한 프로필을 추가로 생성하고 실행하는 방법을 택했습니다.

프로필마다 설정과 데이터가 따로 남아야 했고, 명령어로 프로필을 만들고 관리할 수 있게 구성했습니다.

실행은 생각보다 까다로웠습니다

앱을 열 때 선택한 프로필 설정을 넘기는 부분을 고쳤고, 실행된 세션이 그 프로필의 데이터를 사용하도록 연결했습니다. 이름만 다른 창을 만드는 것으로는 충분하지 않았습니다.

프로필을 분리하는 것보다 실행 중에 서로 섞이지 않게 유지하는 쪽을 더 꼼꼼히 확인하게 됐습니다.

프로필은 생성됐지만 원하는 프로필로 열리지 않았습니다

프로필을 여러 개 만들어 놓고도 앱을 실행할 때 설정이 제대로 전달되지 않으면 결국 같은 창이 열립니다. 앱을 여는 부분에서 선택한 프로필 설정을 넘기도록 바꾸고, 실행된 세션이 그 프로필의 데이터 폴더를 쓰는지도 연결했습니다.

제가 원하는 기능은 프로필이 여러 개 있다는 목록보다 실제로 서로 다른 작업을 이어갈 수 있는 환경이었습니다. 그래서 실행과 저장 위치가 맞물리는 부분을 다시 확인하게 됐습니다.
