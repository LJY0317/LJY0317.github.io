프로필 생성과 관리

Profile management

서로 다른 계정이나 작업에 ChatGPT를 쓰면서 프로필을 바꾸는 일이 번거로웠습니다. 기본 앱은 그대로 두고 추가 프로필을 생성해 따로 실행하는 도구를 만들었습니다. 프로필마다 설정과 데이터를 분리하고 명령어로 관리하도록 했습니다.

Switching ChatGPT profiles for different accounts and work was inconvenient. I kept the base app and added a tool to create and launch extra profiles, each with its own settings and data.

프로필 실행 수정

Launch fixes

프로필을 만들었어도 앱을 열 때 설정이 제대로 전달되지 않으면 원하는 프로필로 실행되지 않았습니다. 앱 실행 과정에서 선택한 프로필 설정을 전달하고, 실행 세션이 해당 프로필의 데이터 위치를 사용하도록 연결했습니다.

A profile could exist without its configuration reaching the launched app. I corrected how the launcher passes the selected configuration and bound the runtime session to that profile's data location.

프로필 생성과 앱 실행은 따로 확인했습니다. 목록에 프로필이 보이는지 확인한 다음, 실행한 앱이 선택한 설정과 데이터 위치를 사용하는지도 살폈습니다.

I checked profile creation separately from the active session, following the selected configuration through to the running app and its data location.
