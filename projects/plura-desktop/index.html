Plura Desktop

Run separate ChatGPT Desktop profiles on one Mac.

View code ↗

Plura creates additional ChatGPT Desktop profiles without replacing the official app.

  • Create and launch additional profile apps.
  • Keep the default ChatGPT app and profile.
  • Install with Homebrew; check profiles from the CLI.

IN CONTEXT

Why separate profiles?

When using ChatGPT for different accounts or work contexts, switching sessions inside one desktop app can get inconvenient. Plura keeps the official Mac app intact and creates a separate launchable app for each managed profile.

You create and manage profiles through the command line, then open them as individual desktop windows. The screenshot shows official ChatGPT windows running under different profiles, not a newly built chat interface.
