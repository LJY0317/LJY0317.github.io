What the team built

Responsibility

What I worked on

I worked on the robot simulation and navigation path: preparing mapping experiments, managing map-related runtime behaviour, connecting navigation flows, and diagnosing integration issues across Gazebo, ROS 2 state, and the operator interface.

Problem

Simulation and navigation components can start without errors while still disagreeing on time, transforms, odometry, localisation, or the map lifecycle. Those failures are difficult to diagnose from the operator interface alone.

Action

  • Ran lower-load world and mapping experiments to isolate simulation and map behaviour.
  • Checked Gazebo, RViz, transforms, odometry, and localisation startup as one connected runtime path.
  • Connected navigation flows with operator state instead of treating each component as an isolated demo.

Result
