ChatGPT Tela

개인 프로젝트 · 개발 중

Personal project, in development

연결 기능

Local tool connections

ChatGPT로 개발 문제를 이야기할 때 파일이나 실행 결과를 계속 복사하는 일이 번거로워 시작했습니다. 채팅과 Codex에서 개발 폴더와 도구를 사용할 수 있게 연결하고, 메뉴 막대에서 연결 상태를 확인하도록 만들고 있습니다.

I started this project to reduce copying files and command output into ChatGPT. It connects Chat and Codex to development folders and tools, with a menu-bar connection status control.

앱 실행 대상 지정

Selecting the target app

여러 Desktop 프로필이 같은 앱 식별자를 사용하면 의도한 프로필이 아닌 다른 앱이 열리는 문제가 있었습니다. 공통 식별자로 실행 대상을 찾던 부분을 고쳐, 열어야 할 앱을 정확히 지정하도록 변경했습니다.

Several Desktop profiles could share an app identifier, causing the wrong app to open. I changed launching to specify the exact target app instead of relying on the shared identifier.

세션 정리 오류

Session cleanup

오랫동안 사용하지 않은 연결을 정리할 때 오류가 처리되지 않는 경우도 수정했습니다. 연결과 실행 기능을 직접 사용하고 시험하면서 개발을 이어가고 있습니다.

I also fixed an unhandled error when cleaning up idle sessions. The project remains in development and is tested through use of its connection and execution features.
