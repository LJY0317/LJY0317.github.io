ChatGPT Tela

ChatGPT 채팅에서 내 개발 폴더와 도구를 연결하고 싶었습니다.

대화창과 개발 환경 사이에서 코드나 실행 결과를 계속 옮겨 적는 것이 번거로워 시작한 연결 도구입니다. 아직 개발 중입니다.

GitHub에서 코드 보기다른 프로젝트 보기

왜 만들었나

채팅으로 개발 문제를 의논하다 보면 실제 폴더를 보여주거나 도구 실행 결과를 복사해서 붙여 넣어야 할 때가 많습니다. 그 과정을 줄이려고 ChatGPT Chat과 Work/Codex에서 로컬 도구를 사용할 수 있도록 연결을 만들고 있습니다.

메뉴 막대에서 연결 상태를 확인할 수 있게 하고, 채팅과 Codex에서 도구에 접근하는 방식을 각각 작업했습니다.

직접 쓰면서 발견한 문제

여러 ChatGPT Desktop 프로필이 같은 앱 식별자를 가질 때 엉뚱한 창을 여는 문제가 있었습니다. 앱 식별자만 믿지 않고 열어야 할 앱을 정확히 지정하도록 수정했습니다.

사용하지 않는 연결을 정리하다 오류가 처리되지 않는 문제도 고쳤습니다. 지금도 실제로 써보면서 연결과 실행 문제를 하나씩 손보고 있습니다.

같은 앱 이름인데 엉뚱한 창이 열릴 때

여러 프로필이 같은 앱 식별자를 사용하면서 처음 의도한 창이 아닌 다른 창이 열리는 문제가 있었습니다. 앱의 이름이나 공통 식별자만 보고 실행할 대상을 정했던 부분을 바꿔, 원하는 앱을 직접 지정하도록 고쳤습니다.

또 오랫동안 사용하지 않은 연결을 정리하는 과정에서 오류가 처리되지 않는 경우가 있었습니다. 실행 중인 일을 방해하지 않으면서 세션을 정리하도록 수정했습니다.
